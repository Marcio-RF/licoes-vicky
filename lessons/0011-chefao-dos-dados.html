O chefão dos dados

Tudo do Mundo 2 misturado, igual na prova. A cada partida o chefão sorteia 20 desafios. ⏱ 20 minutos.

🗺 Seus 6 poderes

  1. 3 jeitos: parte/total → encolha → leve até 100 → ÷ 100. 620 = 310 = 0,3 = 30%.
  2. Variável: palavra/categoria = qualitativa; número de contar ou medir = quantitativa.
  3. Gráficos: barras para comparar, linhas para o tempo, pizza para partes do todo.
  4. Amplitude = maior − menor. Média = soma ÷ quantidade.
  5. Probabilidade = favoráveis ÷ possíveis (de 0% a 100%).
  6. Venn: comece pelo meio; “só” é fora do meio.

Esqueceu algum? A folha de consulta tem tudo. Mas tente lembrar antes de olhar!

📝 Dicas para a prova

  • O professor quer fração, decimal e porcentagem: escreva os 3, lado a lado.
  • Fração: veja se ainda dá para encolher.
  • 5% = 0,05 (não 0,5!).
  • Probabilidade: some o total primeiro.
  • Venn: comece pelo meio; leia a palavra “só”.
  • Gráfico: leia o título antes de tudo.
